# Requirements: Fluent

**Defined:** 2026-05-04
**Core Value:** The AI makes the call the second you hit Send — in your own voice, without ever stuttering.

---

## v1 Requirements

### Authentication

- [x] **AUTH-01**: User can create an account with email and password
- [x] **AUTH-02**: User session persists across browser refresh and tab close
- [x] **AUTH-03**: User can sign out from any page
- [x] **AUTH-04**: Protected routes redirect unauthenticated users to sign-in

### Voice Clone

- [x] **VOICE-01**: User can record a voice sample live in-browser (60–120s, no file upload)
- [x] **VOICE-02**: Recording flow includes a scripted passage to capture varied phonemes without hard-block triggers
- [x] **VOICE-03**: App performs client-side audio quality check (noise floor, silence ratio, volume) before accepting the sample
- [x] **VOICE-04**: User must record and affirm a randomized consent passphrase ("I, [name], on [date], consent to my voice being used by Fluent") before clone is created
- [x] **VOICE-05**: App plays back a sample sentence in the cloned voice for user confirmation before saving
- [x] **VOICE-06**: User can re-clone their voice at any time from Settings — old clone is superseded, not overwritten
- [x] **VOICE-07**: User can delete their voice clone and all associated audio data (GDPR-compliant)
- [x] **VOICE-08**: Voice clone is private to the user — never shared, accessible only by the user and service role

### Call Intent

- [ ] **INTENT-01**: User can type a call goal in plain English (e.g., "Book a table for 4 at 7pm at Mario's")
- [ ] **INTENT-02**: User can enter the recipient's phone number
- [x] **INTENT-03**: User can add 2–3 fallback rules (e.g., "If 7pm is full, try 8pm or a different day")
- [x] **INTENT-04**: User cannot initiate a call without an active voice clone

### Outbound Call Engine

- [x] **CALL-01**: App places an outbound AI phone call using the user's cloned voice when the user submits intent
- [x] **CALL-02**: Every call begins with a hardcoded AI-disclosure preamble before any task content (TCPA/FCC compliance)
- [ ] **CALL-03**: Every call includes a recording-disclosure statement ("This call may be recorded")
- [ ] **CALL-04**: App detects and enforces the plan-tier usage limit before initiating a call (Free: 1/mo, Premium: 10/mo, Pro: unlimited)
- [x] **CALL-05**: Call lifecycle state (draft → initiating → ringing → active → ended → analyzed) is tracked in real time
- [ ] **CALL-06**: End-to-end AI response latency target is <1.5s (using ElevenLabs Flash v2.5 + streaming)
- [ ] **CALL-07**: App handles call failure states (no answer, busy, voicemail, error) with a clear user-facing message
- [x] **CALL-08**: Each call is logged with timestamp, recipient, intent, and call duration

### Live Call Screen

- [ ] **LIVE-01**: User sees a real-time transcript of the ongoing call streamed via Supabase Realtime
- [ ] **LIVE-02**: Transcript visually distinguishes active AI turn ("AI is currently saying") from completed turns
- [ ] **LIVE-03**: User can press a single always-visible "Barge-In" button to unmute their mic and mute the AI agent
- [ ] **LIVE-04**: Barge-in perceived response time is <300ms from button press
- [ ] **LIVE-05**: User can press a distinct "End Call" kill-switch that terminates the call without requiring microphone access
- [ ] **LIVE-06**: App requests microphone permission at app load (not at barge-in time), shows a persistent banner if denied, and explains how to fix it with OS-specific instructions

### Post-Call

- [ ] **POST-01**: After the call ends, user receives a 1-sentence outcome summary generated by Claude (e.g., "Appointment confirmed for Tuesday at 4:00 PM")
- [ ] **POST-02**: Full call transcript is stored and viewable by the user
- [ ] **POST-03**: User can push the call outcome to Google Calendar with a single tap
- [ ] **POST-04**: After Google Calendar push, app confirms success with a "View in Google Calendar" link (verifies the event was created)
- [ ] **POST-05**: User can retry a call with the same intent or an edited version from the post-call screen

### Call History

- [ ] **HIST-01**: User can view a list of all past calls with intent, outcome summary, date, and status
- [ ] **HIST-02**: User can open a past call to see the full transcript
- [ ] **HIST-03**: Call history is paginated or infinitely scrolled for large lists

### Billing & Plans

- [ ] **BILL-01**: Free plan is enforced: maximum 1 call per calendar month
- [ ] **BILL-02**: Premium plan ($19/mo) is enforced: maximum 10 calls per calendar month
- [ ] **BILL-03**: Pro plan ($49/mo): unlimited calls
- [ ] **BILL-04**: User sees their remaining call quota prominently on the dashboard
- [ ] **BILL-05**: User is shown an upgrade prompt (not an error) when they hit their plan limit
- [ ] **BILL-06**: PayPal subscription integration handles plan upgrades and downgrades

## v2 Requirements

### Voice Clone

- **VOICE-V2-01**: Professional Voice Clone option (ElevenLabs Professional tier) for higher voice quality
- **VOICE-V2-02**: Pre-call rehearsal mode — hear the AI speak the opening line before dialing
- **VOICE-V2-03**: "What if they ask…" intent expander — Claude surfaces likely questions before the call

### Call Engine

- **CALL-V2-01**: Multi-language call support (Spanish, French, Hebrew)
- **CALL-V2-02**: Voicemail detection and appropriate leave-a-message behavior
- **CALL-V2-03**: Outcome retry flow — edit a failed call's intent and re-run with one tap

### Social / Sharing

- **SOCIAL-V2-01**: Share a call outcome card (outcome only, no transcript) to contacts

### Mobile

- **MOBILE-V2-01**: iOS/Android native app for improved barge-in UX and background call monitoring

## Out of Scope

| Feature | Reason |
|---------|--------|
| Inbound call handling | Different product. Doubles surface area. Out of scope indefinitely. |
| Real-time AI conversation (caller talks to AI) | Crosses into B2B territory + doubles regulatory complexity. Out of scope. |
| Therapy / fluency training features | Different product category, medical-adjacent, muddies positioning. |
| Team / shared accounts | Solo user product in v1. RBAC + billing complexity not warranted. |
| Voice personality sliders ("more confident") | Implies "you, but better." Wrong message for the audience. |
| In-app analytics ("you saved 14 calls this month!") | Quantifying avoided distress is clinically-framed and creepy. |
| Public voice marketplace or voice sharing | Any sharing UI invites impersonation abuse and destroys privacy promise. |
| Auto-retry on no-answer (AI calls 3× automatically) | Users must consent to each retry attempt individually. |
| Fake disfluencies ("um", "uh") in AI speech | For a stutter-focused product, synthetic disfluencies are deeply ironic. |
| SMS / WhatsApp channel | Different protocol, different regulatory regime. Phone calls only. |
| Stripe billing | PayPal only per global rule. |

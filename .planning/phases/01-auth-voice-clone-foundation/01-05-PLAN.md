**netlify/functions/clone-voice.ts:**

Handler accepts POST with `multipart/form-data` containing:
- `mainAudio` (Blob) — main voice recording from RecordingStep
- `passphraseAudio` (Blob) — consent recording from ConsentStep
- `action` (string) — 'new' or 'reclone'

Steps:
1. Handle OPTIONS preflight (CORS)
2. Verify JWT via `verifyBearerToken(event)` → 401 if invalid
3. Parse multipart body using busboy (event.body may be base64-encoded; check `event.isBase64Encoded`)
4. Validate: both blobs present → 400 if missing
5. If `action === 'reclone'`: UPDATE voice_clones SET status='superseded' WHERE user_id=userId AND status='active'
6. Upload passphraseAudio to Supabase Storage: `voice-evidence/${userId}/consent-${Date.now()}.webm`
7. Call Retell clone API via raw fetch (see interface above) — send both files
8. On Retell success: extract `voice_id` and `preview_audio_url`
9. INSERT into voice_clones: `{ user_id: userId, retell_voice_id: voice_id, status: 'active', sample_url: storagePath, preview_audio_url: preview_audio_url }`
10. Return `{ voice_id, preview_audio_url }`

Error handling:
- If Retell returns non-200: return 502 with `{ error: 'Voice cloning failed' }`
- If Storage upload fails: return 500 (do NOT proceed to Retell if evidence not stored)
- If DB insert fails with unique violation: return 409 (two active clones conflict — shouldn't happen if step 5 ran correctly)

**netlify/functions/delete-voice.ts:**

Handler accepts POST with JSON body: `{ clone_id: string }`

Steps:
1. Verify JWT → 401
2. Fetch voice_clones row WHERE id=clone_id AND user_id=userId AND status='active' → 404 if not found
3. Delete from Retell: `DELETE https://api.retellai.com/delete-voice/${retell_voice_id}`
4. Remove from Storage: `voice-evidence/${userId}/consent-*.webm` (use the sample_url from the DB row)
5. UPDATE voice_clones SET status='deleted' WHERE id=clone_id AND user_id=userId
6. Return `{ success: true }`

If any step fails: log the error but continue (partial GDPR compliance is better than none — user should not be blocked). Return 500 only if DB update fails (audit trail must be maintained).

**netlify/functions/preview-voice.ts:**

Handler accepts GET.

Steps:
1. Verify JWT → 401
2. SELECT voice_clones WHERE user_id=userId AND status='active' → single row
3. Return `{ preview_audio_url: row.preview_audio_url || null, retell_voice_id: row.retell_voice_id }`

The preview_audio_url is stored in the voice_clones table (column added by migration 20260504000003) when the clone is created from the Retell clone response.
